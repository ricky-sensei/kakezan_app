# かけざん爆弾しょりはん!

小学2年生向けの九九練習ゲームです。虫食いになった掛け算の式に、画面右のテンキーで答えを入力します。制限時間内に決められた数だけ正解すればクリア、時間切れになると爆弾が爆発してゲームオーバーです。

公開URL: https://freespaceproud.com/kakezan_app/

## 想定する端末

- **電子黒板（メイン）**: 教室の ELMO Board EL75R2（Android）のブラウザ。1920×1080 の横向き
- **タブレット（ときどき）**: 子どもが横向きで使う。縦向きでも崩れないようにしてある

操作はタッチ（またはマウス）だけで、キーボード入力には対応していません。

## 遊び方

1. 設定画面で「だん」「じかん」「もんだい」を選び、START を押す
2. 3・2・1 のカウントダウンのあとゲーム開始
3. 式の赤い枠に入る数字をテンキーで入力し、ENTER で答える（「けす」で入力を消す）
4. 時間が減るにつれて左下の爆弾が大きくなり、残りわずかになると揺れる
5. 終わったら「もういちど」で再挑戦、「せってい」で設定画面に戻る

### 設定項目

| 項目 | 選択肢 |
| --- | --- |
| だん | すべて / 1〜9のだん |
| じかん | 30 / 60 / 90 / 120 びょう |
| もんだい | 10 / 20 / 30 もん（クリアに必要な正解数） |
| ♪ | 効果音・BGM のオン/オフ（ブラウザに保存される） |

### 出題のしくみ

- 「すべて」ではかける数・かけられる数・こたえのどれか1つを、段を指定したときはかける数かこたえを虫食いにする
- 問題ごとに正解・不正解の回数をブラウザ（localStorage）に記録し、間違えやすい問題ほど出やすくする
- 同じ問題が続けて出にくいようにしている

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 設定画面（入口） |
| `top.html` | 設定を引き継いでゲーム画面へ移動する中継ページ |

ビルドは不要です。HTML / CSS / JavaScript だけで動きます。

## 画面サイズへの対応

`style.css` では、基準デザインでの 1px を `--px` という長さで表し、画面の幅と高さの両方に収まるように全体を拡大縮小しています。高さには、アドレスバーの分を除いた `100dvh` を使います。画面の比率によって基準を切り替えます。

| 画面 | 基準サイズ | レイアウト |
| --- | --- | --- |
| 16:10 より横長（電子黒板など） | 1920×1080 | 問題が左、テンキーが右 |
| 4:3〜16:10 の横向き（タブレット） | 1440×1080 | 同上。文字とテンキーを少し小さくする |
| 縦向き | 1080×1920 | 問題が上、テンキーが下 |

サイズを変えるときは、ブラウザの開発者ツールで 1920×1080・1024×768・768×1024 などを表示し、下が見切れていないか確認してください。

## ローカルで動かす

`index.html` をブラウザで開くだけで動きます。
